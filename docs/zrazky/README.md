# Зразки документів для внесення файлом

Система приймає два типи документів, які можна перетягнути у вікно застосунку. Спершу документ розбирають правила (номер заходу, стан, строк, підрозділи, код ризику); мовна модель допомагає лише там, де правило не дало відповіді, і обирає тільки з переданих кандидатів. Результат — чернетка наявної форми: перевіряє і зберігає дані людина. Документ, що не відповідає зразку, система не приймає і показує, яких полів бракує.

**Усі зразки і тестові документи синтетичні.** Вони описують вигадане «Умовне відомство сектору безпеки і оборони» і згенеровані з набору даних організаторів (`backend/app/datasets/zavdannia-2/`). Від типових документів антикорупційної програми запозичено лише структуру: назви колонок і полів, які збігаються з полями звіту на Порталі доброчесності НАЗК. Реальних документів, їхніх фрагментів, назв реальних підрозділів, номерів наказів чи прикладів із реальних звітів у проєкті немає.

## Зразок A. Звіт виконавця про виконання заходу

Хто подає: виконавець. Куди потрапляє: форма «Внесення за один крок» на картці заходу.

| Поле документа | Обовʼязкове | Поле форми | Звідки назва поля |
|---|---|---|---|
| Номер заходу | ні (без нього захід шукається за змістом) | вибір заходу | звіт Порталу НАЗК |
| Найменування заходу | так | вибір заходу | звіт Порталу НАЗК |
| Звітний період | так | період | звіт за півріччя |
| Фактичний строк виконання | ні | — (для звіту НАЗК визначається системою) | звіт Порталу НАЗК |
| Стан виконання: виконано / не виконано | так | перемикач «Виконано / Не виконано» | звіт Порталу НАЗК |
| Опис результату виконання заходу або пояснення причин невиконання | так | «Опис результату» або «Причини невиконання» | звіт Порталу НАЗК |
| Підтвердні документи (реквізити) | ні | підказка щодо файлів | набір організаторів |

Сам перетягнутий файл прикріплюється до заходу як підтвердний матеріал у момент відправлення на перевірку.

## Зразок B. Картка заходу антикорупційної програми

Хто подає: координатор програми. Куди потрапляє: форма створення заходу.

| Поле документа | Обовʼязкове | Поле форми | Звідки назва поля |
|---|---|---|---|
| Розділ програми (1–3) | ні (без нього визначається за змістом) | «Розділ» | звіт Порталу НАЗК |
| № з/п | ні | «Номер» | таблиця заходів програми / реєстр ризиків |
| Найменування заходу | так | «Назва заходу» | таблиця заходів програми / реєстр ризиків |
| Строк виконання | так | «Плановий строк», «Постійний захід» | таблиця заходів програми / реєстр ризиків |
| Відповідальні за виконання | так | «Відповідальний підрозділ», «Співвиконавці» | таблиця заходів програми / реєстр ризиків |
| Індикатори виконання заходу | так | «Індикатор виконання заходу» (ціль — якщо в тексті є відсотки) | таблиця заходів програми / реєстр ризиків |
| Корупційний ризик | так для розділу 2 | «Корупційний ризик» | таблиця заходів програми / реєстр ризиків |
| Підтвердні документи / примітка | ні | «Які документи потрібні» | таблиця заходів програми / реєстр ризиків |

## Формати файлів

DOCX, XLSX, PDF з текстовим шаром, TXT. Скановані документи без тексту не приймаються.

## Звідки дані в зразках

Лише з синтетичного набору організаторів: заходи (`zakhody`), ризики (`ryzyky`), підрозділи (`pidrozdily`), звіти виконавців (`vykonannia_2026_h1`), умовні підтвердні документи (`pidtverdzhennia`). Опис полів: `backend/app/datasets/zavdannia-2/dictionary.md`.

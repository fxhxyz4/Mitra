# Як рахується ризик

Головне питання системи: **чи зменшився корупційний ризик, на який спрямовані заходи**, а не скільки заходів закрито. Звітність на Порталі доброчесності фіксує лише факт виконання заходу. Щоб показати ефект, Mitra додає до кожного ризику окремий індикатор (KRI) і рахує висновки за явними правилами. Код — `backend/app/services/risk_model.py` (версія правил `RULESET_VERSION`).

## Три шари вимірювання

| Шар | Що показує | Хто визначає | Приклад |
|---|---|---|---|
| 1. Індикатор виконання заходу | що зроблено (вихід) | поле програми НАЗК, вносить виконавець | затверджено порядок, навчено 316 слухачів |
| 2. Індикатор ризику (KRI) | що змінилось (результат) | робоча група: база, ціль, напрям, джерело, лаг ефекту | частка закупівель з одним учасником 45 % → 25 % |
| 3. Рівень ризику НАЗК | наскільки ризик небезпечний | робоча група: ймовірність L × наслідки C, від 1 до 16 | 3 × 4 = 12, критичний |

KRI винесено окремим полем, бо Методологія НАЗК не дозволяє формулювати індикатор виконання заходу як «зниження рівня корупційного ризику». Бали L і C **система не змінює**: вона лише показує підстави для переоцінки (див. нижче).

## 1. Прогрес одного KRI

Позначення: B — база (фіксується при затвердженні програми), T — ціль, C — останнє значення на дату розрахунку.

```
менше — краще:  p = (B − C) / (B − T)
більше — краще: p = (C − B) / (T − B)
p обрізається до [−1; 1]
```

Поправки, щоб показник не можна було «намалювати»:
- **Поріг шуму δ.** Якщо |C − B| < δ, то p = 0. Для часток δ = max(5 в.п.; 2·√(B·(1−B)/n)), де n — обсяг вибірки. Для інших показників δ задає робоча група, без цього δ = 0.
- **Самозвітні дані.** Якщо джерело KRI не незалежне (`independent = false`), позитивний прогрес множиться на 0,5. Негативний враховується повністю.
- **Очікуваний прогрес.** Вважаємо, що від початку програми до дедлайну цілі показник рухається рівномірно. Тоді на дату розрахунку він мав би пройти частку шляху `(дата − початок) / (дедлайн цілі − початок)`.

Стан KRI за прогресом:

| Умова | Стан |
|---|---|
| немає вимірювань | немає даних |
| p < 0 | погіршення |
| p < 0,1 | без змін |
| p нижче очікуваного | рухається, але відстає від графіка |
| інакше | на траєкторії |

## 2. Показник зниження ризику RRS

Ризик може мати кілька KRI з вагами w. Ваги нормуються лише серед тих KRI, що мають дані:

```
RRS = Σ wᵢ · pᵢ
```

| RRS | Категорія |
|---|---|
| ≥ 0,666 | суттєве зниження |
| 0,333 – 0,666 | часткове зниження |
| 0,1 – 0,333 | незначне зниження |
| 0 – 0,1 | без змін |
| < 0 | погіршення |

**Приклад (закупівлі продовольства).**
- KRI₁ «один учасник»: B = 45 %, T = 25 %, C = 40 %, n = 120. Поріг шуму δ = 9,1 в.п., а зміна становить лише 5 в.п., тому p₁ = 0.
- KRI₂ «перевищення ціни»: B = 18 %, T = 8 %, C = 13 %, тож p₂ = 0,5.
- RRS = 0,6 · 0 + 0,4 · 0,5 = **0,20**: незначне зниження.

## 3. Вердикт «виконання × ефект»

Для кожного ризику система поєднує два факти: чи є виконані заходи і в якому стані індикатор.

| | Індикатор рухається | Без змін | Погіршення |
|---|---|---|---|
| **Є виконані заходи** | заходи працюють | закрито «на папері» | погіршення попри виконання |
| **Виконаних заходів немає** | покращення без виконаних заходів | заходи не виконано, змін немає | ризик росте без реакції |

Окремі вердикти: «немає даних індикатора» і «немає заходів щодо ризику».

**Прапорці на заході розділу 2.** Їх ставлять, коли захід виконано або подано як виконаний:
- **F1 «Формальне закриття»**: RRS < 0,1, у ризику немає KRI або немає вимірювань.
- **F2 «Погіршення попри виконання»**: RRS < 0.

Лаг ефекту (місяці, для кожного KRI свій) не відкладає висновок, а позначає його як **попередній** до дати «виконання + лаг». Обидва прапорці знімає лише керівник.

**Приклад із демо-набору: ВЛК, ризик KR11.**
- Заходи 2.23 і 2.24 виконано.
- KRI змінився з 25 % до 26 % при цілі 95 %. Зміна на 1 в.п. менша за поріг шуму 5 в.п., тож p = 0.
- Вердикт: «закрито на папері», прапорець F1 (попередній, поки не мине лаг 6 місяців).

## 4. Підстави для переоцінки ймовірності (бал не змінюється)

| Код | Умова | Що пропонується |
|---|---|---|
| L−1 | RRS ≥ 0,666 на кінець двох останніх кварталів | знизити ймовірність на 1 (не нижче 1) |
| L+1 | RRS < 0 на кінець двох останніх кварталів | підвищити ймовірність на 1 (не вище 4) |
| P1 | підтверджений інцидент молодший 6 / 12 / 36 місяців, а ймовірність у реєстрі нижча за 4 / 3 / 2 | ймовірність щонайменше 4 / 3 / 2 |

Рішення ухвалює робоча група. Координатор вносить новий бал з обґрунтуванням, і це фіксується в журналі дій. Система перевіряє лише, щоб рівень відповідав балу за Методологією НАЗК: 1–2 — низький, 3–4 — середній, 6–9 — високий, 12–16 — критичний.

## 5. Сигнали якості даних і маніпуляцій

| Код | Умова |
|---|---|
| T1 | настав дедлайн цілі, а p < 1 |
| D1 | немає вимірювань, останнє старше за рік або вибірка менша за мінімальну |
| B1 | базу чи ціль змінено після затвердження програми (хеш не збігається) |
| X1 | основний KRI покращився, а парний погіршився: ризик міг «перетекти» |
| S1 | критичний або високий ризик закривається лише навчальними заходами розділу 3 |

## 6. Показники програми: PRI, EXEC, FCG

Вага ризику I = L × C, тож небезпечніші ризики важать більше.

```
PRI  = Σ Iᵣ · RRSᵣ / Σ Iᵣ                     наскільки реально знизились ризики
EXEC = Σ Iᵣ · частка виконаних заходів / Σ Iᵣ   наскільки закрито заходи («Частково» = 0,5)
FCG  = EXEC − PRI                             розрив формального виконання, в.п.
```

| FCG | Колір |
|---|---|
| < 10 в.п. | зелений |
| 10–25 в.п. | жовтий |
| > 25 в.п. | червоний |

Що ще показує система:
- **Найбільший внесок у розрив:** ризик із найбільшим I · (частка виконаних − RRS).
- **Найслабша ланка:** мінімальний RRS серед критичних ризиків (I ≥ 12).
- **Окремий субіндекс для розділів 1 і 3:** заходи без ризику в PRI не входять, для них рахується середній прогрес їхніх власних індикаторів.

**Приклад.**

| Ризик | I | RRS | Виконано заходів |
|---|---|---|---|
| A. Закупівлі | 12 | 0,2 | 100 % |
| B. Житло | 6 | 0,8 | 50 % |
| C. ВЛК | 9 | 1,0 | 100 % |

- PRI = (2,4 + 4,8 + 9) / 27 = **60,0 %**.
- EXEC = 24 / 27 = **88,9 %**.
- FCG = **28,9 в.п.**, червоний. Найбільший внесок у розрив дає ризик A.

Метрика «закрито заходів» показала б тут 89 % і «успіх».

На демо-наборі станом на 06.07.2026 Executive Dashboard і сторінка «Модель ризику» показують:
- EXEC 63,2 %;
- PRI 41,1 %;
- FCG 22,1 в.п. (жовтий);
- закрито «на папері» 3 з 12 ризиків із виконаними заходами: KR02, KR11, KR12.

## Застереження

- **Офіційної формули немає.** НАЗК не має офіційної формули зниження ризику. Це надбудова команди, сумісна з Методологією: бали ставлять люди, а система лише перевіряє їх даними.
- **Неоднозначні показники.** Зростання кількості виявлених випадків може означати кращий контроль, а не більше корупції. Такі показники неоднозначні, тож напрям і джерело KRI має обґрунтувати робоча група.
- **Роль ШІ.** ШІ в розрахунках участі не бере. Модель може лише переказати пояснення простою мовою з посиланнями на ті самі числа.
